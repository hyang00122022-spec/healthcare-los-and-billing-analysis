# Healthcare Analytics: Length of Stay (LOS) & Billing Analysis

**Author:** Tao Jingchu 
**Domain:** Healthcare Informatics & Data Analytics

## Overview

This project analyzes a healthcare dataset using Python, exploratory data analysis, data cleaning, visualization, and statistical testing.

The main focus is on hospital Length of Stay (LOS) and Billing Amount.

## Research Questions

- Does Length of Stay differ across Admission Type groups?
- Is there a linear relationship between Length of Stay and Billing Amount?
- Does Billing Amount differ across Admission Type or Insurance Provider groups?

## Methods

- Data Cleaning
- Duplicate Detection
- Date Conversion
- Feature Engineering
- Exploratory Data Analysis
- Data Visualization
- Pearson Correlation
- ANOVA
- Levene's Test
- Q-Q Plots
- Kruskal-Wallis Test

## Key Findings

No statistically significant difference in Length of Stay was detected across Admission Type groups.

No statistically significant linear association was detected between Length of Stay and Billing Amount.

Billing Amount also did not show statistically significant differences across the examined Admission Type and Insurance Provider groups.

## Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy
